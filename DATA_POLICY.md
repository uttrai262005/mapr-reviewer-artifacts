# Data policy

## Privacy
This repository is built from real student work, but the public package includes only anonymized derived artifacts.

## Included
- anonymized assignment-level score tables
- anonymized reviewer benchmark tables
- rubric files
- agent pipeline definitions and implementation code
- aggregate analysis outputs

## Not included
- raw submissions
- original classroom identifiers
- personally identifying student files
- submission text, images, PDFs, or DOCX source answers
