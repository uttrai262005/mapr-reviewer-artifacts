# Output package

This directory is organized into three reviewer-facing groups:

1. `01_single_agent_results/`
   - assignment-level anonymized score tables from the single-agent pipeline
   - full-dataset total scores for A1-A4

2. `02_multi_agent_results/`
   - full-dataset total scores for A1-A4 from the multi-agent pipeline

3. `03_comparison_metrics_and_subsets/`
   - human evaluation subset
   - external baseline model outputs used for benchmark comparison
   - recomputed metrics, ablation tables, and audit summaries
